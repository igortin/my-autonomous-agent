# my-autonomous-agent

## Week 10 Lesson 1
Cтатическая классификация специализированных tools.  


Категория инструмента определяется Python кодом и проверяется непосредственно перед исполнением.
 
 #### Категории
| Категория         | Значение                                                                              |
|-------------------|---------------------------------------------------------------------------------------|
| READ              | Читает состояние без намеренного изменения управляемых ресурсов                       |
| WRITE             | Меняет состояние инфраструктуры                                                       |
| DESTRUCTIVE       | Выполняет операцию с существенным потенциалом необратимой потери ресурсов или данных  |
